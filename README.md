# UniVerse — Frontend Prototype

## Run the project
1. Extract the `UniVerse` folder.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension if you do not already have it.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Sign in with any username and password. Choose a role to enter the demo.

## Project structure
- `index.html` — login / entry page
- Separate HTML pages for each campus module
- `css/style.css` — shared design system and responsive styles
- `js/script.js` — shared navigation, page content and demo interactions

## Important prototype notes
- This is a frontend learning prototype.
- Demo sign-in is not secure authentication. The password is not verified or stored.
- Some dashboard numbers, events, routes, and directory entries are sample data.
- Complaint submissions are stored in the current browser using LocalStorage.
- LocalStorage is not a shared database. Other users/devices will not see the same data.
- No real email/SMS, GPS tracking, backend, or genuine AI service is connected.
